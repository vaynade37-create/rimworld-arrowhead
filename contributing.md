## 🛡️ Keeping A Save Intact

A trainer that ruins a hundred-hour save is worse than no trainer. A few habits
remove almost all of that risk.

**Copy the save first**

Every trainer session starts with a copy of the save directory. It takes seconds
and it is the only real insurance. Anything that goes wrong is then a two-minute
fix instead of a lost campaign.

**Change one value at a time**

Set a value, play a minute, confirm nothing broke, then move to the next. Changing
six values at once means you cannot tell which one caused a problem — and you will
not have the original state to compare against.

**Avoid freezing calculated values**

Freezing a displayed stat is safe. Freezing a value that sits inside a formula can
propagate into other systems and produce a save that behaves strangely long after
you turn the trainer off.

**Watch for these signals**

| **Signal** | **Meaning** |
| --- | --- |
| Value snaps back immediately | the game recomputes it — server or script driven |
| NPC behaviour changes | you froze something used in AI |
| Save takes much longer to load | the file grew unexpectedly |
| Quests stop progressing | a prerequisite value is out of the expected range |

**If something goes wrong**

Close the game without saving, restore the copy, and try the change again in
isolation. Do not try to repair a broken save by writing more values to it.
